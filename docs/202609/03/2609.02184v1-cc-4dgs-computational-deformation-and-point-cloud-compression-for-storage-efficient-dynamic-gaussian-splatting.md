## 摘要
动态四维（4D）高斯泼溅（Gaussian Splatting）已成为一种用于高质量新视角合成的强大显式表示，然而由于现有方法严重依赖大型多分辨率哈希表和高维高斯属性，每个场景仍需要几十到几百兆字节的存储空间。本文提出了 CC-4DGS，一种存储高效且具可扩展性的框架，重新审视了变形建模与标准属性存储。首先，我们引入了计算变形场（CDF），它利用确定性密集哈希编码和紧凑神经解码器取代了大型多分辨率可学习哈希表，在将每个场景的变形存储降低至仅 1–3 MB 的同时，实现了变形特征的即时合成。其次，我们提出了标准点云属性压缩（CCA）管线，通过条件自编码、选择性量化和残差码本压缩高维球面调和外观项及辅助高斯属性，在质量损失微乎其微的情况下实现了 3–5 倍的点云数据量削减。结合这些组件，所构建的统一表示在保留实时渲染性能的同时将总存储空间降至 20–30 MB。在 N3DV 和 Technicolor Light Field 数据集上的大量实验表明，CC-4DGS 取得了与 Swift4D 等最新前沿方法相当的重建精度，同时显著提升了存储效率，并提供了良好的运行时间与内存开销权衡。

## Abstract
Dynamic four-dimensional (4D) Gaussian Splatting has emerged as a powerful explicit representation for high-quality view synthesis, yet existing methods still require tens to hundreds of megabytes per scene due to their heavy reliance on large multi-resolution hash tables and high-dimensional Gaussian attributes. This paper presents CC-4DGS, a storage-efficient and scalable framework that rethinks both deformation modeling and canonical attribute storage. First, we introduce a computational deformation field (CDF) that replaces large multi-resolution learnable hash tables with deterministic dense hash encoding and compact neural decoders, enabling on-the-fly synthesis of deformation features while reducing deformation storage to only 1--3 MB per scene. Second, we propose a compression of canonical point-cloud attributes (CCA) pipeline that compresses high-dimensional spherical harmonic appearance terms and auxiliary Gaussian attributes via conditional autoencoding, selective quantization, and residual codebooks, achieving 3--5$\times$ point-cloud reduction with negligible quality loss. Together, these components yield a unified representation that preserves real-time rendering performance while reducing total storage to 20--30 MB. Extensive experiments across the N3DV and Technicolor Light Field datasets demonstrate that CC-4DGS achieves reconstruction accuracy comparable to state-of-the-art methods such as Swift4D, while offering significantly improved storage efficiency and favorable runtime-memory trade-offs.

### 2. 论文提出的方法论

CC-4DGS 由两大核心模块组成：**计算变形场（CDF）** 和 **规范点云属性压缩（CCA）**。

#### (1) 计算变形场（Computational Deformation Field, CDF）
* **无哈希表特征合成（Hash Feature Decoder）**：
  * **确定性密集哈希编码（DHE）**：利用矩阵投影和模运算将规范空间的高斯中心顶点坐标映射为多维确定性整数哈希签名，并归一化至 $[-1, 1]$ 连续空间，消除可学习的隐式存储表。
  * **轻量级神经解码器**：为每个网格分辨率分配一个极小的 MLP（线性层+Mish+LayerNorm），即时（On-the-fly）将确定性哈希签名解码为连续变形特征，将变形模块的存储需求从数十/数百 MB 剧降至仅 **1–3 MB**（具体约 1.9 MB）。
* **时间编码与 FiLM 融合机制**：
  * 使用正弦位置编码（Frequency Encoding）将时间戳 $t$ 转换为高维向量，经浅层 TimeMLP 抽取时间特征 $f_{\text{time}}$。
  * 采用 **Feature-wise Linear Modulation (FiLM)** 机制，利用时间特征对空间网格特征 $f_{\text{voxel}}$ 进行通道级缩放与平移调制，生成时空融合特征 $f_{\text{ST}}$。
  * **主干-分支网络（Trunk-Branch Network）**：通过共享 Trunk 提取全局变形上下文，再由独立 Branch 预测位置、缩放、旋转、透明度和 SH 系数的动态偏移量 $\Delta \theta$。
* **计算效率优化策略**：
  * **顶点复用（Vertex Reuse）**：消除相邻/相同体素内重复顶点的冗余解码操作，构建映射索引以降低 GPU 计算开销与显存占用。
  * **时空特征缓存（Spatiotemporal Feature Caching）**：利用规范空间静态不变的特性，在 $t=0$ 帧预先计算并缓存空间特征 $f_{\text{voxel}}$，后续帧直接读取缓存并仅推理时间分支，恢复 $O(1)$ 级别的查询效率。
* **平滑正则化损失**：在训练阶段引入局部时空扰动的平滑损失 $L_{\text{smooth}}$，抑制显式网格易出现的闪烁伪影。

#### (2) 规范点云属性压缩（Compression of Canonical Point-Cloud Attributes, CCA）
* **属性敏感度分流处理**：
  * **无损保留**：高斯中心位置 $\mu$ 与球面调和直流分量（SH-DC）对几何形变和基础颜色极敏感，保留 32-bit 浮点数完整精度。
  * **标量属性选择性量化**：旋转 $r$、缩放 $s$、透明度 $o$ 采用 12-bit 线性量化；长尾分布的动态得分 $d$ 先经过 **$\mu$-law 压缩扩展（Companding）** 映射再行量化。
  * **SH-AC 高维外观项压缩**：拼接几何与状态条件后传入**条件自编码器（Conditional Autoencoder）**压缩为低维隐向量 $z$；使用基于 K-means 的 256 项**残差码本（Residual Codebook）**补偿重建误差。
  * **无损熵编码**：最终流经过 Zstandard (zstd) 压缩打包归档。

### 6. 论文的主要结论与发现

1. **存储大幅压缩**：CC-4DGS 将动态 4DGS 的变形模块存储从 Swift4D 的 68.4 MB（Grid4D 为 221.1 MB）降至 **1.9 MB**；结合 CCA 后，整场景总存储降至 **20–30 MB**，相比 Swift4D 缩小了近 80%。
2. **质量无损/微损**：在大幅压缩的前提下，重建质量（N3DV PSNR 32.06 dB，SSIM 0.943）与 Swift4D（32.06 dB）及 4DGS 基本持平，视觉细节（如火焰、高频纹理、边缘）保持良好。
3. **实时渲染保留**：借助特征缓存与顶点复用，稳态渲染下的网格计算耗时降至 0.8 ms，整体帧率达到 **110+ FPS**（Technicolor 上达 64+ FPS），满足实时渲染要求。
4. **计算与存储的 Trade-off 成立**：证明了在动态场景表示中，用即时计算的“轻量神经解码器”取代静态存储的“大型可学习哈希表”在工程和理论上均行之有效。

### 7. 论文的优点（亮点）

* **范式创新（Learnable Hash-Table-Free）**：巧用确定性密集哈希编码与神经解码器组合，打破了 Instant-NGP / Grid4D 依赖海量显式可学习哈希参数的固化思路。
* **解耦优化与缓存加速**：巧妙利用规范空间的静态不变性进行特征缓存，完美解决了“神经解码器即时计算会拖慢实时渲染”的矛盾。
* **全栈式协同压缩**：同时攻克了“变形场存储”与“点云属性存储”两大瓶颈，且提供可控的率失真调节档位。
* **实验严谨详实**：不仅给出了整体结果，还深入到了单帧 Latency 拆解、长序列延展、算力/存储交换比率的定量测量。

### 8. 不足与局限

* **训练时间成本偏高**：由于基于原生 PyTorch 实现且解码器包含 LayerNorm / Mish 等算子，未开发融合 CUDA 内核（Fused CUDA Kernels），导致训练迭代耗时比 Swift4D 慢约 1.9 倍（单场景需 64 分钟）。
* **长序列衰减问题**：在 1200 帧长序列测试中，PSNR 出现了约 0.5 dB 的下降。这是单规范空间（Single Canonical Template）模型固有的容量瓶颈，需引入 GoP 分段或层次化时间编码方能彻底解决。
* **FiLM 模块具有场景依赖性**：消融实验显示，FiLM 在部分场景下带来高达 +4.19 dB 的提升，但在个别场景下略逊于直接拼接（$-0.57$ 至 $-1.01$ dB），表明机制仍有待普适化改进。
